## Deploying to GitHub Pages

1. Push all files to a GitHub repository (with `index.html` in the root).
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then **Save**.
4. After a minute, your live link appears at the top of the Pages settings. Paste it into this README and submit it.
