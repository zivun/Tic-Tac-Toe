## Running the game
Open `index.html` in a browser. No build step or dependencies are needed. Choose two players or play the computer (easy or unbeatable); scores are kept across rounds.

- `index.html`: page structure
- `style.css`: layout and colour theme
- `script.js`: game rules, computer opponent and event handling

## Built with Jekyll
The site is a Jekyll site, so GitHub Pages builds it automatically. `_config.yml` holds the site settings. To preview locally, run `bundle install` then `bundle exec jekyll serve` and open http://localhost:4000.
